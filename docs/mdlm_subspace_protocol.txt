auxiliary prior/weights and source-disjoint assignments already saved.

Readout: a fixed random orthonormal vocabulary projection in the zero-sum

Methods: empirical radius-two reconstructor, full source covariance,
source covariance with cross-lag products removed, smoothed multinomial

covariance diag(p)-p p^T as a frequency-only control.
Keep the same 2048-chunk reference as the matched main-text experiment.
Do not select a reference or tuning value from neural alignment outcomes.

Empirical matrix: average Delta Delta^T over masked positions within each

2*(n*G/n_ref)/(G-1). Keep whole sources and all overlapping token pairs.

and diag(P)-P P^T with the same scalar coefficients as the existing trace.

Ranks k=1,2,4,8,16. Primary compact table: n=2048, 12000 updates, d=64,k=4.

Random-subspace null: Haar orthonormal k-dimensional subspaces in the same

Interpretation: subspace overlap does not imply calibrated total variance
or pointwise signed alignment. Positive overlap against a random null may
reflect token frequency, hence the unigram control. An advantage of full
source covariance requires comparison with multinomial and same-lag source
predictions. Neural and linear procedures retain their documented training
differences. Three pairs, one mask rate and one reference bank limit claims.
